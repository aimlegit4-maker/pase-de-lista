Preparando aplicación
Prototipo de demostración, no usar todavía con datos reales. El docente registra la asistencia escaneando el QR del estudiante. No se solicita la ubicación; para usar la cámara desde el celular, el sitio debe tener HTTPS.

Instala Pase de Lista en tu celular

Se agrega a la pantalla de inicio y se abre como una app; no necesitas descargar un APK ni buscarla en una tienda.

Android: abre este enlace en Chrome y elige «Instalar app» o «Agregar a pantalla principal». iPhone: abre el enlace en Safari, toca «Compartir» y luego «Agregar a pantalla de inicio».

Para instalarla y usar cámara o ubicación, el enlace debe estar publicado con HTTPS. La dirección localhost o HTTP de la red Wi-Fi sólo sirve para una prueba local.
